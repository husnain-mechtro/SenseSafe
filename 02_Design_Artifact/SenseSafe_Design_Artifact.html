01 · Overview

SenseSafe

A low-cost LPG monitoring prototype. The ESP32-C3 SuperMini reads an MQ-2 module, triggers local warnings, displays status on its integrated OLED, and serves the SenseSafe website and simulated dashboard over Wi-Fi.

02 · Design approach

Local warning logic with device-hosted web interface

The sensor is sampled and filtered by the ESP32-C3. A configurable raw-value threshold sets NORMAL or WARNING. The buzzer and LED are controlled locally, while the integrated OLED shows a compact status/readout. The same ESP32-C3 serves the portfolio, design file and simulated dashboard from LittleFS.

Engineering principles

  • Keep sensing and alarm logic on the ESP32-C3.
  • Power MQ-2 from a regulated 5 V source.
  • Scale analogue output before the 3.3 V ADC.
  • Use a driver-equipped buzzer module or transistor stage.
  • Mark all readings as raw sensor values until calibrated.
  • Use the integrated 72 × 40 OLED for local state and raw reading.
  • Serve the website locally from LittleFS via ESP32 WebServer.

03 · Architecture

Layered sensing and communication

Signal/data paths are shown horizontally. The OLED is an on-board I²C display (common SDA GPIO5 / SCL GPIO6); power distribution is represented separately below.

Communication protocol

Browser → ESP32-C3: HTTP GET request to the local web server. The device responds with JSON from /api/telemetry, including device ID, sequence, raw ADC demo value, threshold, state and output flags.

{
  "device": "SS-01",
  "seq": 42,
  "raw_adc": 812,
  "threshold": 760,
  "status": "WARNING",
  "buzzer": true,
  "led": true
}

The JSON fields are a proposed response format, not a record from an operating sensor. The dashboard is served by the same ESP32-C3; no cloud service is needed for the demo.

Failure handling

FailureResponse / fallback
Wi-Fi or server downContinue local alarms; retry telemetry with timeout/backoff.
Sensor unplugged / invalid rangeRaise SENSOR FAULT; do not display NORMAL.
Power cycleInitialise safely and show warm-up/stabilisation state.
High reading persistsKeep buzzer/LED active until reading falls below a lower reset threshold (hysteresis) or user acknowledges.

Industry reference: Honeywell

Honeywell's fixed gas and flame detection portfolio illustrates continuous monitoring, near-real-time data and integration with industrial control systems (including Modbus/HART on relevant products). SenseSafe adapts the basic sensor-to-alert-to-dashboard concept for a student-scale prototype; it does not match certified industrial reliability, sensing accuracy or hazardous-area approvals.
