SenseSafe is an ESP32-C3 SuperMini with 0.42-inch OLED and MQ-2 based LPG monitoring prototype. It combines local audible and visual warnings, an onboard status display, and a dashboard served directly by the ESP32.

01 · Project overview

Connected monitoring for a practical safety problem

LPG is used in homes and small commercial spaces across Pakistan. SenseSafe demonstrates how a low-cost sensor node can detect changes in combustible-gas response, provide an immediate local alert and make sensor status visible through a web dashboard.

01 / Sense

Continuous input

MQ-2 module provides an analogue sensor signal to the ESP32-C3.

02 / Respond

Local alert

Threshold logic activates the buzzer and LED without depending on Wi-Fi.

03 / Connect

IoT dashboard

Wi-Fi telemetry is designed to report readings, device state and alert events.

02 · Engineering approach

Prototype architecture

Controller + display

ESP32-C3

SuperMini with integrated 0.42-inch OLED.

Gas sensor

MQ-2

Broad response to combustible gases and smoke; raw ADC is not ppm.

Outputs

Buzzer + LED

Local audible and visual warning indicators.

Signal flow

MQ-2 AO is scaled by a 12kΩ / 10kΩ divider to GPIO0 (ADC1_CH0). The common onboard OLED is 72 × 40 SSD1306-compatible, I²C SDA GPIO5 / SCL GPIO6, address 0x3C. Verify the board revision before wiring.

Prototype limitation: MQ-2 requires warm-up and calibration, is cross-sensitive and is not a certified life-safety detector. SenseSafe is a student prototype and must not replace an approved gas alarm.

05 · Device-hosted delivery

Website hosted on the ESP32-C3

The ESP32-C3 serves the portfolio, dashboard and HTML artifact from its LittleFS filesystem using an HTTP web server. In access-point mode, connect to the SenseSafe Wi-Fi network and open http://192.168.4.1. In station mode, connect the board to the same router as the visitor and use the board's local IP. The dashboard is simulated for this proposal-stage demonstration. A GitHub repository holds the source files and firmware.

This is a local-network / device-hosted website, not an Internet-wide public URL by default. Access from outside the local network needs separate networking and security work.
